# 💰 Expense Tracker

A simple **command-line Expense Tracker** built with Python as part of my **DecodeLabs Python Programming Internship**.

The application allows users to enter multiple expense amounts and keeps a running total of their spending. Users can enter expenses continuously and type `done` when they have finished.

## ✨ Features

* 💵 **Add Expenses** — Enter expense amounts one by one.
* 🔄 **Continuous Input** — Add multiple expenses during a single session.
* 📊 **Calculate Total** — Automatically calculates the total amount spent.
* 🚫 **Input Validation** — Handles invalid or negative expense values.
* ✅ **Finish Tracking** — Type `done` to stop entering expenses.
* 📋 **Expense Summary** — Displays the final total spent.

## 🛠️ Technologies Used

* **Python 3**
* Variables
* Loops
* Conditional Statements
* User Input
* `float()` Conversion
* Exception Handling
* Accumulator Logic

## ▶️ How to Run

Make sure **Python 3** is installed on your system.

Run the following command in your terminal:

```bash
python expense_tracker.py
```

## 💻 Usage

After starting the program, enter your expenses one by one:

```text
Enter expense: 100
Enter expense: 50
Enter expense: 20
Enter expense: done

===== Expense Summary =====
Total Spent: 170.00
```

Type `done` when you have finished entering expenses.

## 🎯 Learning Objective

This project focuses on practicing **mathematical operations, loops, user input, input validation, and accumulator logic** in Python.

The core concept is maintaining a running total:

```python
total += expense
```
