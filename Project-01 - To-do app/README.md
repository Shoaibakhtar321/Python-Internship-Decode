# 📝 To-Do List

A simple **command-line To-Do List application** built with Python as part of my **DecodeLabs Python Programming Internship**.

The application allows users to add tasks, view their existing tasks, and exit the program through a simple interactive menu.

## ✨ Features

* ➕ **Add Task** — Add a new task to your To-Do List.
* 📋 **View Tasks** — Display all added tasks with numbered entries.
* 🚫 **Empty Task Validation** — Prevents empty tasks from being added.
* ❌ **Exit** — Safely exit the application.
* 🔢 **Interactive Menu** — Easy-to-use command-line interface.

## 🛠️ Technologies Used

* **Python 3**
* Lists
* Loops
* Conditional Statements
* User Input
* `enumerate()`
* Basic Input Validation

## 📂 Project Structure

```text
To-Do-app/
│
└── todo.py
```

## ▶️ How to Run

Make sure Python 3 is installed on your system.

Run the following command in your terminal:

```bash
python todo.py
```

## 💻 Usage

After running the program, choose an operation from the menu:

```text
1. Add task
2. View tasks
3. Exit
```

Enter `1` to add a task, `2` to view your tasks, or `3` to exit the application.
